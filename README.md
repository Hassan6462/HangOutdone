# HangOut — Spontaneous Meetups Web App

A modern React & TypeScript web application rewritten from the Android project. HangOut lets users discover what's happening nearby, post spontaneous hangout plans, join groups with a single tap, and coordinate details in real-time chat.

## Features

- **Nearby Feed & Filter**: Browse spontaneous hangouts with remaining spots, activity tags, timing, and host information. Filter by activity categories (Sports, Coffee, Food, Gaming, Walk, etc.).
- **Interactive Map View**: Visual local map view showing pins for all active nearby hangouts with click-to-preview cards.
- **Post a Hangout**: Fast creation flow with 12 activity presets, time horizons (Right now, In 1 hour, This evening, Tomorrow), group size limit, and automatic location detection with manual override.
- **Real-Time Group Chat**: Interactive chat room for each hangout featuring text messages, quick emoji reaction drawer, and photo sharing.
- **User Profiles**: Profile details showing name, verified age, trust rating, selected interests, and list of posted hangouts.
- **Authentication & Setup**: Phone OTP verification flow, email sign-in, and full 3-step profile onboarding (name/DOB, photo picker, interests multi-select) with instant demo profile switcher.

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide React Icons
- Canvas Confetti
